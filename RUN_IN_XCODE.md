# Task 3 — Run in Xcode (Storyboard)

1. Create a new project: `iOS App` (`UIKit`, `Storyboard`, `Swift`).
2. Place project folder near this repository.
3. Copy lab sources into app folder:
   ```bash
   cp -r ../task3/src/* ios_app/
   ```
4. In Xcode:
   - make sure `Main.storyboard` is in target membership;
   - `DoctorProfileViewController.swift` is in target membership;
   - `Main.storyboard` has initial controller and class `DoctorProfileViewController`.
5. Set `Signing & Capabilities` Team and run (`Cmd+R`).
