# Лабораторная работа №3

В этой работе подготовлен экран профиля врача в `Storyboard` с использованием `Auto Layout`.

Состав файлов:
- `Main.storyboard` - описание интерфейса;
- `DoctorProfileViewController.swift` - контроллер с `IBOutlet` для связи элементов интерфейса с кодом;
- `control_questions.md` - ответы на контрольные вопросы.

Примечание: в тексте задания изображение примера экрана отсутствует, поэтому выбран нейтральный экран профиля врача, который логически связан с лабораторными №5 и №6.

## Минимальный запуск в Xcode

1. `File -> New -> Project -> iOS App (UIKit, Swift, Storyboard)`.
2. Добавить в проект файлы:
   - `Main.storyboard`
   - `DoctorProfileViewController.swift`
3. В `Main.storyboard` назначить класс контроллера: `DoctorProfileViewController`.
4. В `Signing & Capabilities` выбрать `Team`.
5. Запустить на симуляторе (`Cmd+R`).
